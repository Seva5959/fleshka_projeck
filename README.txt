OfflineTube — офлайн-библиотека видео

Структура на флешке:
  Запустить.bat   - двойной клик, откроется браузер
  server.py       - сканирует videos/ и раздаёт приложение
  app/index.html  - интерфейсф
  videos/<Плейлист>/001 - Название.mp4
  data/likes.json - лайки (создаётся сам)

Скачивание: в yt-dlp замените -P на  <флешка>\OfflineTube\videos\<Имя плейлиста>
Лучше -P "...\videos\%(playlist_title)s" -- тогда папка создастся сама.

Если видео не играет (чёрный экран / ошибка в плеере) - дело в кодеке.
Скачивайте в H.264 + AAC, этот формат играет везде:
  -f "bv*[vcodec^=avc1]+ba[acodec^=mp4a]/b[ext=mp4]/bv*+ba/b"
Уже скачанное можно перекодировать (нужен ffmpeg):
  ffmpeg -i "in.mp4" -c:v libx264 -c:a aac "out.mp4"
